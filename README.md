# Luxury CK Design · Vista del diseño

Página pública que abren el cliente y el instalador con el QR o el link que genera la app **Luxury Design**.

- El diseño viaja dentro del link (después de `#d=`), comprimido; esta página no guarda ni recibe datos de ningún servidor.
- `index.html` es la versión en español y `en/index.html` la versión en inglés.
- No se edita a mano: se genera desde el repo `Luxury-design` con `npm run viewer`, que escribe la carpeta `site/`, y se copia aquí.
